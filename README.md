# لمسة ذهب — Gold Touch Marketer

تطبيق مجاني متخصص **حصرياً** في إنتاج صور تسويقية عالية الجودة للمنتجات الذهبية، باستخدام Gemini من Google.

## كيف يعمل

المستخدم يرفع صورة واحدة فقط، ثم يعمل التطبيق تلقائياً في الخلفية دون إظهار أي خطوة للمستخدم:

1. **تحليل الصورة** — يحدد الذكاء الاصطناعي هل الصورة سكتش مرسوم يدوياً، أم صورة فعلية لمنتج ذهبي، أم صورة غير متعلقة بالذهب (ويتم رفضها بلطف لأن التطبيق متخصص في الذهب فقط).
2. **إذا كانت سكتش** — يتم تحويلها إلى صورة فوتوغرافية واقعية للمنتج الذهبي الفعلي كما لو تم تصنيعه، مع خلفية تسويقية إبداعية ولمسة فنية لرفع جودة التسويق.
3. **إذا كانت صورة منتج حقيقي** — يتم فصل المنتج عن خلفيته الأصلية، ورفع جودة الصورة ووضوحها، ثم وضعه على خلفية تسويقية إبداعية جديدة أكثر احترافية.

النتيجة النهائية فقط هي ما يظهر للمستخدم.

## البنية التقنية

- `services/geminiService.ts` — يحتوي كامل منطق التحليل والتوليد (`analyzeImage` ثم `generateShoppingImage`).
- `App.tsx` — واجهة بسيطة: رفع صورة واحدة + زر "أنشئ الصورة التسويقية" + عرض النتيجة وسجل الصور السابقة.
- يعمل على الحصة المجانية اليومية المتاحة لمفتاح Gemini API (`gemini-2.5-flash` للتحليل و`gemini-2.5-flash-image` للتوليد).

## التشغيل محلياً

**المتطلبات:** Node.js

1. تثبيت الحزم:
   `npm install`
2. ضع مفتاح Gemini API الخاص بك في ملف [.env.local](.env.local) في المتغير `GEMINI_API_KEY`
   (يمكن الحصول على مفتاح مجاني من https://aistudio.google.com/apikey)
3. تشغيل التطبيق:
   `npm run dev`
